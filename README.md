# Kastle 2 Label Maker

Do you have an idea for Kastle 2 firmware? Use this to vizualize it! Not Pixel Perfect™️, but good enough for quick sketches. Supports draft save & load and PNG export (PDF export coming).

## Available at

https://apps.bastl-instruments.com/kastle2-labelmaker/


## Develop

⭐️ `npm install`

🦺 `npm run dev`

🛸 `npm run build`
